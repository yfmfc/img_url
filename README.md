# Image Toolkit —— SillyTavern 图片工具箱扩展

一个不带独立悬浮窗、不写自定义 HTML 界面的 SillyTavern 插件。
面板挂在 SillyTavern 自带的「扩展设置」抽屉里，全部控件使用 ST 原生按钮/输入框样式和主题变量，
自动跟随你当前的 SillyTavern 主题，手机端自适应。

**整个插件就是一个收纳按钮**：默认只显示一行「Image Toolkit」，点开才显示 4 个功能区；
每个功能区再点击展开具体控件，不占屏幕空间。
每个功能标题栏右侧有一个「说明」小按钮，点开才显示使用说明，不点不占空间。

## 安装

1. 找到 SillyTavern 安装目录下的 `public/scripts/extensions/third-party/`
2. 把本文件夹（`image-toolkit`）整个放进去
3. 重启 SillyTavern（或刷新页面）
4. 打开顶部「扩展」→「扩展设置」，拉到最底部即可看到「Image Toolkit」

> 也可以在 SillyTavern 的「扩展 → 从 URL 安装扩展」中指向本文件夹所在的 git 仓库。

## 功能一：聊天记录清理

- 输入「距今 N 天」，选择过滤方式：
  - **按角色最后聊天时间**：角色卡最后一次聊天距今超过 N 天
  - **按每条聊天最后消息时间**：逐条聊天判断最后消息时间
- 点击「扫描」→ 列出符合条件的角色卡（最后聊天时间 / 聊天数 / 占用空间）
- 点「详情」展开该角色的每条聊天（最后消息时间 / 条数 / 大小）
- 勾选（支持全选/全不选）→ 「删除所选聊天」→ 确认后批量删除
- **当前打开的聊天会被自动跳过**，防止删坏当前状态

底层接口（均已对照官方源码）：
`POST /api/characters/all`、`POST /api/characters/chats`、`POST /api/chats/delete`

## 功能二：图片插入（宏）

1. 「图片插入」→「上传图片」（可多选；默认自动压缩到 1280px）
2. 点「复制宏」得到 `{{img::图片名}}`
3. 把宏粘贴到**任意位置**：世界书条目、角色描述/人设、预设提示词、聊天记录……
4. 发送请求时，宏会被替换成真正的图片内容，随请求一起发给多模态 API
5. **点击缩略图可预览大图**，右上角 X 或 ESC 退出预览

原理：请求发出前把 `<img src="data:...">` 转成 API 标准的 `image_url` 内容块，
SillyTavern 服务端会自动转换成 Claude（base64 image block）/ Gemini（inlineData）/ OpenRouter 等各家格式。
文本补全类 API 不支持图片，会自动降级为 `[图片: 名称]` 文字，不会把 base64 灌进提示词。

- 「启用宏替换」开关：关掉后宏输出为空（省 token）
- 支改名、删除
- ⚠️ 需要使用支持视觉的模型；若 ST 的「媒体内联」关闭或 API 不支持图片，自动降级为文字

## 功能三：Preset JSON 编辑 / 整理器

- 「上传」载入 .json，或直接在输入框里**手动编辑 JSON**
- 「整理」：读取 `prompt_order` 中的 ID 顺序，把 `prompts` 数组按此顺序重排
- **除 `prompts` 数组元素顺序外，任何数据都不修改**（ID、内容、enabled、role、marker、
  injection 参数、采样参数、prompt_order、甚至对象内部字段顺序全部原样保留）
- 「复制」/「导出」按钮导出漂亮格式化 JSON（缩进 2/4/紧凑可选）
- **查找 / 替换**（点工具栏「查找/替换」展开）：下一处（自动高亮定位+滚动）、替换、全部替换

示例：`prompt_order` 为 ID_C → ID_A → ID_B，则 `prompts` 重排为
`ID_C → ID_A → ID_B`。不在 `prompt_order` 里的条目按原相对顺序补到末尾。

## 功能四：图片格式转换

- 「选择图片」（可多选）
- 目标格式：**JPG / PNG** 互转
- **质量滑杆**（对 JPG 有效，PNG 为无损格式）
- **缩放滑杆**（10%–100%，两者都有效）
- 每张转换结果显示 `宽×高 · 原大小 → 新大小`，逐张「下载」

> JPG 无透明通道：透明背景会自动铺白底。

## 说明

- 图片本体存在浏览器 IndexedDB，不占 SillyTavern 设置文件体积
- 全部数据本地存储，不上传任何外部服务
- 删除聊天为不可恢复操作，请自行备份
