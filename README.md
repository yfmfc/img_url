# TavernKit v3.0.0 —— SillyTavern 工具箱

一个杂项工具性质的 SillyTavern 插件。面板挂在「扩展设置」抽屉里，
**横排分类 Tab** 切换功能组，全部控件使用 ST 原生样式和主题变量，自动跟随当前主题，手机端自适应。

| Tab | 功能 |
|---|---|
| **实用** | 聊天记录清理、图片宏 |
| **文件** | 查找替换 / 整理（Preset JSON）、图片格式转换 |
| **状态机** | FN 函数：世界书声明状态，AI 随剧情维护 |

## 安装

1. 找到 SillyTavern 安装目录下的 `public/scripts/extensions/third-party/`
2. 把本文件夹（`tavernkit`）整个放进去
3. 重启 SillyTavern（或刷新页面）
4. 打开顶部「扩展」→「扩展设置」，拉到最底部即可看到「TavernKit」

> 旧版（Image Toolkit）用户直接覆盖文件夹即可，图片库、设置全部保留。

## 状态机（FN 函数）——v3.0.0 新增

让 AI 随剧情维护一组状态（年龄、好感度、物品、地点……），**单一数据源、值随聊天记录走**：
删楼层自动回滚、新聊天回到默认值，设定文本和状态永远一致（没有"设定说18、状态说19"的污染）。

### 三步用法

1. **声明字段**：世界书里写定义块（标签名可自定义，块数不限、可分散在多个条目）：

   ```html
   <fn定义>
   小明的年龄 = "18"
   小明的心情 = "平静"
   </fn定义>
   ```

   正文里用 `{{fn:名字}}` 引用当前值：`小明是{{fn:小明的年龄}}岁的少年。`

2. **复制维护提示词**：在「状态机」Tab 点「复制维护提示词」，新建一个世界书条目粘贴进去。
   内容告诉 AI 什么时候更新、怎么输出，标签自动替换为你自定义的标签名。

3. **AI 自动维护**：AI 在回复末尾输出更新块（发请求前自动剥离，模型看不到）：

   ```html
   <fn更新>
   小明的年龄 = "19"
   </fn更新>
   ```

### 语法要点

- 一行一个字段：`名字 = "值"`，等号/全半角冒号均可；值可为任意文字（引号可加可不加）
- 名字不需要包裹符号；随手加的 `[名字]`、`【名字】`、`"名字"` 会自动剥掉
- 同名字段：块内后行覆盖前行；多块之间后出现的覆盖先出现的（重复会记日志）
- `名字 =` 空值 = 清除，渲染回落默认值
- 解析失败的行跳过并记录（面板状态行 + 控制台），绝不猜测

### 开关与自定义

- 总开关：停用后完全不动提示词
- 两个标签名（函数定义标签 / AI 维护输出标签）随意改，避开你预设里已有的标签
- 「复制函数模板」按钮：复制一条现成格式，照着写就行

## 功能一：聊天记录清理（实用）

- 输入「距今 N 天」，按角色最后聊天时间 / 每条聊天最后消息时间过滤
- 扫描 → 勾选 → 批量删除；**当前打开的聊天自动跳过**；删除不可恢复，请自行备份

## 功能二：图片宏（实用）

- 上传图片（默认压缩到 1280px）→ 「复制宏」得到 `{{img::图片名}}`
- 粘贴到**聊天消息**中即可让模型看到图片（请求发出时解析为图片内容块，base64 不进正文）
- 目前仅支持聊天消息；世界书 / 系统提示词区域暂不支持（后续改进）
- 发送模式：发送图片 / 输出文字标记 / 停用宏输出；点击缩略图预览大图

## 功能三：查找替换 / 整理（文件）

- 载入 .json 预设 → 查找替换（支持全部替换、回车查找下一处）
- 「整理」按 `prompt_order` 的 ID 顺序重排 `prompts` 数组，其余数据原样保留
- 导出整理结果

## 功能四：图片格式转换（文件）

- JPG / PNG 互转，质量滑杆（对 JPG 有效）、缩放滑杆（10%–100%）
- 每张显示 `宽×高 · 原大小 → 新大小`，逐张下载；透明背景转 JPG 自动铺白底

## 说明

- 图片本体存浏览器 IndexedDB，不占设置文件体积
- 全部数据本地存储，不上传任何外部服务
